# 水果保卫战

简单休闲小游戏 · iOS / macOS

## 关于

果园主题的射击小游戏。操控飞船击破飞来的水果泡泡，连击得分、升级闯关。

- 经典街机手感，单局随时开玩
- 支持音效与震动反馈
- 记录最高分与累计击破数

## 源码

`game/` 目录：

- `DisguiseGalleryView.swift` — 游戏主界面与逻辑
- `GameSFX.swift` — 程序化音效
